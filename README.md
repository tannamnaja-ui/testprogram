# สรุปการทดสอบโปรแกรม HOSxP XE

หน้าเว็บแสดงผลการทดสอบ HOSxP XE โดยดึงข้อมูลสดจาก Google Sheet

## วิธีเปิดใช้งาน

ดับเบิลคลิก `start.bat` ระบบจะเปิดที่ http://localhost:4001/

ห้ามเปิด `index.html` จากไฟล์โดยตรง เพราะ Google Sheet ไม่อนุญาตให้หน้าเว็บที่เปิดแบบนั้นดึงข้อมูล ถ้าจะให้คนอื่นใช้ ให้วาง `index.html` ไว้บนเว็บเซิร์ฟเวอร์ (เช่น IIS) ก็ได้

## ความสามารถ

- เมนูตรงกับชื่อแท็บในชีท ได้แก่ สรุป, HOSxP V4, PPL, Inventory, Cloud และ New Feture
- กรองได้ตามกลุ่ม ประเภท ผลการทดสอบ ผู้ทดสอบ และช่วงวันที่ และค้นหาข้อความได้
- หน้าสรุปคำนวณจากข้อมูลปัจจุบัน แยกตามกลุ่ม ประเภท และผู้ทดสอบ
- อัปโหลดรูปและดูรูปประกอบได้ รูปเก็บใน Google Drive และลิงก์จะถูกเขียนลงชีท

## ตั้งค่าการอัปโหลดรูป

1. ติดตั้ง Apps Script ตามขั้นตอนที่เขียนไว้ต้นไฟล์ `apps-script/Code.gs`
2. นำ URL ของเว็บแอปไปใส่ในค่า `UPLOAD_URL` ใน `index.html`

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด |
| `server.ps1`, `start.bat` | เว็บเซิร์ฟเวอร์ในเครื่อง ใช้พอร์ต 4001 |
| `apps-script/Code.gs` | สคริปต์รับรูป บันทึกลง Drive และเขียนลิงก์ลงชีท |
